# BOSBM EA Hosting SOP Document Summary

This document outlines BOSBM's automated EA hosting solution, positioning itself as a MetaQuotes Virtual Hosting alternative.

## Key Features

The platform enables customers to "buy BOSBM EA license → one-click deploy to VPS → run 24/7" without direct server access, instead monitoring via dashboard.

## Onboarding Process

The system automates VPS rental, EA deployment using Wine + MT5, broker connection setup, and customer notification through a streamlined workflow completed in approximately 10 seconds.

## Technical Infrastructure

The solution integrates multiple API endpoints and database systems to connect customer applications with containerized environments running on LXD pools, supporting connections to major brokers.

## Revenue Model

The document projects single-customer lifetime value at approximately NT$55,000 over five years, combining EA licensing revenue with monthly hosting fees, targeting NT$11M annual recurring revenue from 1,000 customers.

## Current Status

AI Savior v8 EA is available with 14-day free trial or subscription options (NT$1,500 monthly or NT$15,000 annually), with demonstration infrastructure already operational using containerized MT5 instances.
